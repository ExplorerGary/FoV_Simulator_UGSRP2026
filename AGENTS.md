# Repository agent instructions

- Any change to LR prediction inputs, features, targets, fitting, trace split,
  calibration, policy conversion, baselines, bandwidth/QoE evaluation, HPC
  scripts, paths, schemas, or reported results MUST update
  `explanation_lr.md` in the same commit.
- Add a dated entry to the Change log in `explanation_lr.md` for every such
  change. Do not describe unrun experiments as completed results.
- `explanation_lr.md` is tracked documentation and must never be ignored.
